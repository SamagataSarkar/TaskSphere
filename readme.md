# TaskSphere 

> "Great work starts with a clear space." 

TaskSphere is a full-stack project management workspace designed to help teams bring their projects, people, and priorities together. Built with a focus on clean UI and rock-solid backend security, it allows users to manage workspaces, track real-time task metrics, and collaborate efficiently.

## 🚀 Use & Application

TaskSphere is built for both individual productivity and team collaboration. Its core capabilities include:
*   **Secure Workspaces:** JWT-based authentication with secure password reset and profile management flows.
*   **Project Organization:** Create active projects, invite team members via secure email tokens, and archive completed projects to a read-only history state.
*   **Task Management:** Create, assign, and track tasks with strict priority levels (`HIGH`, `MEDIUM`, `NORMAL`) and deadlines.
*   **Real-time Dashboard:** Instantly view high-level metrics for Active, Completed, and Overdue tasks across your workspace.

## 🛠️ Tech Stack
*   **Frontend:** React, Tailwind CSS, Lucide Icons, Vite
*   **Backend:** Java, Spring Boot, Spring Security, Hibernate/JPA
*   **Database:** Relational SQL Database (MySQL/PostgreSQL)
*   **Security:** JSoup (HTML Sanitization), Bucket4j (Rate Limiting)
